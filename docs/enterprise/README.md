# Enterprise pack

Documents for a security or procurement review of the verit hosted dashboard.
These are docs, not new product features. They describe what is built today, and
they never imply a control verit does not hold.

- [`security-overview.md`](security-overview.md): two-page overview. Data flow,
  what executes where, what is stored.
- [`security-questionnaire.md`](security-questionnaire.md): stock answers to the
  usual vendor questions.
- [`dpa-template.md`](dpa-template.md): a Data Processing Addendum template for
  your legal review. A starting point, not an executed agreement.
- [`not-yet.md`](not-yet.md): what verit does not have yet, dated. No SOC 2, no
  SSO, no audit log. Read this alongside every other page.

Ground truth for stored fields and retention: [`../data.md`](../data.md).
Incident procedures: [`../runbook.md`](../runbook.md).
