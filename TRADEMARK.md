# Trademark

"verit" is a trademark, not just a repository name.

The code is AGPL-3.0-only. You can run it, modify it, and redistribute it,
including as a fork, under the terms of that license. The license does not
give you the right to use the name "verit" for the result.

A fork must not use "verit" or a confusingly similar name:

- as the name of an npm package, including under a different scope
  (`@yourscope/verit` is not allowed)
- as the name of a GitHub Check Run
- in a domain name or subdomain hosting a fork
- as the name of the project itself, in its README, marketing, or app name

Rename your fork before you publish it. Pick a name that does not read as
"verit" with a prefix or suffix bolted on.

This restriction covers the name only, not the license terms, and it does
not apply to accurate, factual statements that a project is a fork of verit
("based on verit", "a fork of verit's prove pipeline") in body text, as
opposed to the name presented to users.
